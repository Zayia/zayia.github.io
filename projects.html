为什么是「未签名」

iOS 上没法像安卓那样直接装一个 apk。苹果要求每个 App 都有有效签名，所以这里只提供编译好的 未签名 IPA，由你在自己设备上用免费 Apple ID（或自有证书）重签一次。 这样做的好处是不需要 Apple 开发者账号，也不用经过 App Store 审核；代价是免费证书 7 天有效，到期重签即可。

安装步骤

  1. 下载上面的 IPA 到电脑（Windows / macOS 都行）。
  2. 用 Sideloadly（推荐）、 AltStore 或轻松签 / ESign 这类工具，把 IPA 拖进去、填自己的 Apple ID、开始签名安装。
  3. 首次安装后到 设置 → 通用 → VPN 与设备管理 里信任你的证书，然后就能打开游戏。
掉签或 7 天过期后，重新签名覆盖安装即可，不要先删除 App——删掉会连同存档一起清空。 安装时保持 Bundle ID 不变，存档就能一直延续。

怎么做的

无名杀本体是纯 Web 应用，安卓端用 Capacitor 套了一层 WebView。iOS 端没有引入任何第三方依赖， 只用系统自带的 WKWebView + Network.framework：

能力 实现
承载 原生 WKWebView
加载 内置本地 HTTP 服务 127.0.0.1:19530，等价于 PC 端的 noname-server
只读资源 App 包内 Bundle/web
可写目录 Documents/Noname（「文件」App 可见），同名文件覆盖内置资源
扩展 / 存档 复用游戏自带的 @noname/fs HTTP 接口，和安卓版玩法一致

为什么用本地 HTTP 而不是 file://：后者在 WKWebView 下 ES Module、fetch、 IndexedDB 都会受限，而游戏强依赖 IndexedDB 存档、以及 640MB 音频的 Range 请求。 用 http://127.0.0.1 就是一个正常 Web 源，行为与桌面浏览器一致。

装扩展

和安卓一样，往游戏目录放文件就能加功能：

  • 游戏内：选项 → 扩展 → 获取扩展 → 导入扩展，选一个 zip 包即可；
  • 或者用「文件」App 把扩展文件夹放进 我的 iPhone → 无名杀 → Noname/extension/， 再打开 选项 → 通用 → 自动导入扩展。

自动更新

官方仓库一有更新，GitHub Actions 每天自动重新构建并发布新版本：拉取官方 main → 叠加 iOS 客户端 → 编译 → 打包 → 发 Release。所以这里的 IPA 会一直跟着官方走， 版本号可以在游戏内 选项 → 其它 → 更新 里核对。
